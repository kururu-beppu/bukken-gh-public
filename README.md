# bukken-gh-public

別府市内のゲストハウス/シェアハウス向け賃貸物件の一覧（公開・認証不要）。

- 公開ページ: https://kururu-beppu.github.io/bukken-gh-public/
- `bukken-gh-data.json` は Mac mini 常駐の `fox-bukken-crawl`（`~/dev/fox-bukken-crawl/crawl.py`）が
  毎朝8:30に自動更新・push する。**手で編集しない**（次のクロールで上書きされる）。
- 内部の運用ダッシュボード（Cloudflare Accessで社内限定）にある同名データの公開ミラー。
  くるるの内部リンク・ナビは含まない、独立した最小限のページ。
- 元データ・詳しい経緯は `kururu-beppu/kururu-machizukuri` リポジトリと
  Discord `#🏡ゲストハウス` チャンネルを参照。
